# Scripts Directory

This directory contains utility scripts for the Smart Cabinet System.

## Database Management Scripts
- `migrate_violation_system.py` - Adds violation prevention tables and columns
- `reset_instruments.py` - Resets all instruments to available status
- `add_instruments.py` - Adds instruments to the database

## Testing Scripts
- `test_violation_system.py` - Tests the violation prevention system
- `test_fixed_system.py` - Tests the fixed system functionality
- `test_action_selection.py` - Tests action selection feature
- `test_simple_login.py` - Tests login functionality
- `test_employee_dashboard.py` - Tests employee dashboard access

## Debug Scripts
- `check_logs.py` - Checks access logs
- `debug_login.py` - Debugs login issues
- `check_employees.py` - Checks employee data
- `check_roles.py` - Checks employee roles
- `check_employee_3.py` - Checks specific employee

## Employee Management Scripts
- `add_ahmed.py` - Adds Ahmed Abdi employee
- `update_ahmed_role.py` - Updates Ahmed's role
- `fix_employees.py` - Fixes employee data
- `test_roles.py` - Tests role functionality
- `add_role_migration.py` - Adds role migration
- `test_put_instrument.py` - Tests instrument PUT endpoint
